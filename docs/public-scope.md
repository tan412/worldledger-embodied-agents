# Public release scope

Included:

- the WorldLedger architecture report in English and Chinese;
- a compact claim-to-source index and release metadata;
- the evidence kernel and selected trajectory / verification scripts;
- selected tests and public robot-profile metadata;
- compact, path-free summaries for the cited engineering cases;
- an optional MCP service and local stdio client skeleton.

Excluded:

- personal names, home directories, internal hostnames, private IP addresses, SSH targets, and deployment paths;
- internal source snapshots and server-only production packages;
- raw videos, full trajectory archives, checkpoints, and multi-gigabyte run directories;
- third-party robot meshes and vendor data whose redistribution terms were not cleared;
- the exploratory locomotion, video-search, recovery-learning, and sequence-learning pilots that are outside the report's research question.

The omitted material remains in the original working directory for internal use. The public summaries preserve denominators and evaluation scope without claiming that the omitted material is public or independently reproducible.
